# Сахалинская Энергия — AI-фотоинсталляция

Фотокиоск для «Сахалинской Энергии»: гость фотографируется у стенда, выбирает
локацию и через пару минут получает фотореалистичный кадр — он сам на объекте
компании в фирменном худи. Кадр оформляется в карточку, которую можно
распечатать, забрать по QR-коду или получить на почту.

Сделан на движке фотоинсталляции «Машина времени: Сахалин».

## Как это работает

1. **Съёмка.** Камера киоска или загрузка с телефона по QR. Кадр проверяется
   (insightface): лицо достаточно крупное, одно, не смазано.
2. **Генерация.** Лицо, корпус гостя, эталон локации и фирменный знак уходят
   в модель на Replicate (`google/nano-banana-pro`). Одежда задаётся в
   `config.py`: тёмно-синее худи с основным логотипом на груди.
3. **Сходство.** Перенос настоящего лица гостя (face-swap), затем варианты
   ранжируются по ArcFace — гость видит лучшие и выбирает один.
4. **Карточка.** Фото с подписью локации, знак «Сахалинской Энергии»,
   поздравление и подвал. Печать, QR на цифровую версию, письмо.

## Запуск локально

```bat
app\run.bat
```

Откройте http://localhost:8000. Без `REPLICATE_API_TOKEN` работает демо-режим
с заглушками — весь путь гостя можно пройти без затрат.

## Настройки (`app/backend/.env`)

Шаблон — `app/backend/.env.example`, файл `.env` в git не попадает.

| Параметр | Назначение |
|---|---|
| `REPLICATE_API_TOKEN` | Токен Replicate. Генерация платная; при балансе меньше $5 провайдер режет скорость. |
| `PUBLIC_BASE_URL` | Адрес сайта для QR-кода, например `https://ваш-домен`. |
| `VARIANTS` | Сколько вариантов генерировать на гостя. |
| `GEN_MODE`, `FACE_MIN_PX`, `FACE_SWAP`, `FACE_ENHANCE`, `FACE_DESHADOW` | Режим генерации и качество лица — рабочие значения уже в шаблоне. |
| `CARD_GREETING` | Поздравление на карточке и в письме. Пусто — строки нет. |
| `SMTP_*` | Почтовый ящик для отправки карточек. |
| `PRINT_QUEUE_KEY` | Ключ страницы очереди печати `/print-queue` и агента `tools/print_agent.py`. |

## Локации

Описаны в `app/backend/locations.json`: название, слоган, эталон, промпт,
подпись на карточке. Сейчас работает **СПГ «Пригородное»**; вторая локация
(`location_2`) — заглушка «Скоро» с `enabled: false`. Чтобы включить её,
положите эталон в `assets/references/`, заполните `reference`, `prompt`,
`card_caption` и поставьте `enabled: true`.

## Фирменный стиль

По «Руководству по фирменному стилю» Общества:

- тёмно-синий `#101840`, королевский синий `#274497`, светло-голубые акценты;
- шрифт Montserrat;
- фон — контур острова Сахалин (стилеобразующий элемент);
- знаки извлечены из руководства и лежат в `tools/brand/`; значки вкладки и
  экрана «Домой» пересобираются скриптом `tools/gen_favicon.py`.
